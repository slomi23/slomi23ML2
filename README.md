# slomi23_ML_Assignment_2

# IEEE-CIS Fraud Detection
გადმოგვეცემა მონაცემები ტრანზაქციების შესახებ, 400 მდე სვეტის სახით (ზოგი ტრანზაქციას ეხება, ზოგი ადამიანის იდენტობას), და უნდა გავარკვიოთ ყალბია თუ არა.

განვიხილე სამი ვარიანტი
1. ლოჯისტიკური რეგრესია target encoding იტ და shap ით
2. bagging random forest, bootstrap ასევე target encoding იტ და shap ით
3. XGBoost + target encoding
shap rfe ის ვარჩიე დიდი დატას ზომის გამო. XGBoost ის შემთხვევაში კარგ შედეგს არც იძლეოდა შაპის გამოყენება. ასევე დიდი ზომის გამო არ ჩავთვალე საჭიროდ kfold ის გამოყენება

ფაილების განმარტება:
model_experiment



ჰიპერპარამეტრებს რაც შეეხება, ტესტირებების შედეგად აღმოჩდნა რომ XGBoost ის მოდელების რაოდენობა 9000 იყო ოპტიმალური (8000 ზე და 10000 ზე ნაკლები შედეგი მივიღე)

საბოლოო მოდელად ავარჩიე ბოლო მოდელი, XGBoost. roc ქულა ჰქონდა 0.91 და ვალიდაციის სქორის ახლოს იყო და ოდნავ ცამორჩებოდა ტრეინის სქორს.
